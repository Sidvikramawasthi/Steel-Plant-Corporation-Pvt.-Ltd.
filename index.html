Analytical approach
Predictive analytics

Companion Python pipeline compares Logistic Regression, Decision Tree, Random Forest, KNN, SVM and Gradient Boosting using class-sensitive metrics, then tunes Random Forest using macro-F1.

Clustering and associations

K-Means groups similar defect records. Association rules explore co-occurrence between steel grade, thickness bands and fault categories. Neither establishes causation.

Dataset, source and limitations

Source: Buscema, Terzi & Tastle (2010), UCI Machine Learning Repository, Steel Plates Faults. Dataset DOI.

1,941 records, 27 numeric predictor features and seven fault categories. No all-inspected-plate denominator, non-defective records, timestamps, machine/line/operator identifiers, production volume, scrap/rework disposition or financial costs.
